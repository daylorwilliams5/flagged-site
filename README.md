# FLAGGED — public pages

The privacy policy and support pages for the FLAGGED iOS app. Published with
GitHub Pages because App Store Connect requires both to be publicly reachable
without a login, and to keep resolving after launch.

- `index.html` — landing page
- `privacy-policy.html` — use as the Privacy Policy URL
- `support.html` — use as the Support URL

The source of truth is the app repository under `store/`. Edit there, then copy
the files here and push.
